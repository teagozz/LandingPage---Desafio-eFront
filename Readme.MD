## 🎯 Funcionalidades

- **Validação de Formulário Inteligente:** Verificação em tempo real de campos obrigatórios (Nome com mínimo de 3 caracteres e E-mail validado através de _Regex_).
- **Sistema de Modais Dinâmicos:** Exibição de um modal interativo informando o status do cadastro (**Sucesso** ou **Erro**), estilizado dinamicamente pelo JavaScript (`<dialog>`).
- **Design Totalmente Responsivo:** Adaptado perfeitamente para diferentes resoluções de telas através de _Media Queries_ (desktops, tablets e smartphones).
- **Reset Automático:** Limpeza automática dos campos do formulário após o envio.
